# RPGMVP Просмотрщик

Android-приложение (Kotlin) для просмотра зашифрованных картинок
RPG Maker MV/MZ (`.rpgmvp`, а также `.png_` для MZ) — без предварительного
дешифрования файлов на компьютере.

## Как это работает

1. Вы выбираете папку с игрой (через системный диалог — Storage Access
   Framework), например корневую папку игры, где лежат `www/` или `data/`
   и `img/`.
2. Приложение рекурсивно находит все файлы `.rpgmvp` / `.png_`, а также
   файл `System.json`, в котором RPG Maker хранит ключ шифрования
   (`encryptionKey`).
3. Каждая картинка расшифровывается «на лету» (XOR первых 16 байт файла
   ключом из `System.json`, остальные данные — обычный PNG) и показывается
   как миниатюра в сетке.
4. По тапу открывается полноэкранный просмотр с зумом (щипок/двойной тап)
   и свайпом между изображениями.

Никакие файлы на диске не изменяются и не пересохраняются — расшифровка
происходит только в памяти, при отображении.

## Важно

- Ключ шифрования достаётся из `System.json`, поэтому нужно выбирать
  папку, где этот файл присутствует (обычно это корень игры или папка
  `www`, `data` внутри неё — сканирование рекурсивное, так что можно
  выбрать и саму корневую папку игры).
- Если приложение пишет «ключ НЕ найден» — значит `System.json` не найден
  в выбранной папке или в нём нет поля `encryptionKey`.

## Сборка проекта

В этой среде нет доступа к интернету и Android SDK, поэтому собранного
`.apk` файла нет — но есть полный исходный код проекта Android Studio.

Как собрать:

1. Установите Android Studio (актуальную версию).
2. Откройте эту папку (`RpgMvpViewer`) через `File → Open`.
3. Android Studio автоматически предложит создать Gradle Wrapper —
   согласитесь (или дождитесь синхронизации — она сделает это сама).
4. Дождитесь окончания синхронизации Gradle (потребуется интернет для
   загрузки зависимостей AndroidX/Material — они скачиваются один раз).
5. Нажмите Run ▶ на подключённом устройстве или эмуляторе
   (минимальная версия Android — 7.0, API 24).

## Структура проекта

```
app/src/main/java/com/rpgmvpviewer/app/
├── MainActivity.kt          — экран выбора папки и сетка миниатюр
├── ImageAdapter.kt          — адаптер сетки, декодирует и кэширует миниатюры
├── FileScanner.kt           — рекурсивный поиск файлов через SAF/DocumentFile
├── RpgMakerDecryptor.kt     — сам алгоритм расшифровки .rpgmvp
├── ViewerActivity.kt        — полноэкранный просмотр (ViewPager2)
└── ZoomableImageView.kt     — ImageView с поддержкой зума/панорамирования
```

## Возможные доработки

- Поддержка расшифровки аудио (`.rpgmvo` → `.ogg`) по тому же алгоритму.
- Экспорт расшифрованных PNG на устройство (кнопка «Сохранить»).
- Сортировка/группировка по подпапкам (`img/pictures`, `img/characters`
  и т.д.).
